# ホームAPI

## ホーム取得

- どの画面で使う？

ホーム画面

- メソッドは？

GET（取得だから）

- URLは？

/api/home

- リクエストは何が必要？

なし


- レスポンスは画面に何を表示したい？

【近日の予約】

予約ID
ペット名
予約日
病院名
通院の目的

（各予約を押下すると、予約登録/編集画面へ遷移する仕様のため、予約IDをレスポンスとして返す）

【前回通院】

ペット名
通院日
病院名
通院の目的

（前回通院は過去の通院履歴として表示のみ行うため、予約IDは返さない）

【最新体重】

体重ID
ペット名
測定日
体重

（各体重を押下すると、体重登録/編集画面へ遷移する仕様のため、体重IDをレスポンスとして返す）

【最新のひとこと】

ひとことID
ペット名
記録日
ひとこと

（各ひとことを押下すると、ひとこと登録/編集画面へ遷移する仕様のため、ひとことIDをレスポンスとして返す）
