なし

## 体重新規登録

- どの画面で使う？

体重登録/編集画面（登録画面）

- メソッドは？

POST（登録するから）

- URLは？

/api/weight-records

（登録前はまだ体重記録が存在しないから、IDは指定しない。更新時との違いは、更新時はすでにIDがあるから）

- リクエストは何が必要？

ペットID
測定日
体重

（バックエンドが識別できる情報を渡せばいいから「ペット名」じゃなくて「ペットID」を渡す）

- レスポンスは画面に何を表示したい？

登録結果
体重ID

（一覧画面で使う情報は体重一覧取得APIを使うから、↑以外の情報必要ない）

## 体重削除

- どの画面で使う？

体重登録/編集画面（編集画面）

- メソッドは？

DELETE（削除するから）

- URLは？

/api/weight-records/{id}

（どの体重を削除するのか体重IDで指定）

- リクエストは何が必要？

なし（登録済みの体重を削除するだけだから。削除する体重はURLの体重IDで識別できる）

- レスポンスは画面に何を表示したい？

削除結果
体重ID

（一覧画面で使う情報は体重一覧取得APIを使うから、↑以外の情報必要ない）
