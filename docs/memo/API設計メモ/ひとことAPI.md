## ひとこと削除

- どの画面で使う？

ひとこと登録/編集画面（編集画面）

- メソッドは？

DELETE（削除するから）

- URLは？

/api/notes/{id}

（どのひとことを削除するのかはひとことIDで指定）

- リクエストは何が必要？

なし（登録済みのひとことを削除するだけだから。削除するひとことはURLのひとことIDで識別できる）

- レスポンスは画面に何を表示したい？

削除結果
ひとことID

（一覧画面で使う情報はひとこと一覧取得APIを使うから、↑以外の情報必要ない）
