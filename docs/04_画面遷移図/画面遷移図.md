# 画面遷移図

## 基本の画面遷移

ホーム
├─ ペット一覧
│   ├─ [+ペット登録]ボタン → ペット登録
│   └─ 各ペット → ペット編集
├─ 予約一覧
│   ├─ [＋予約登録]ボタン → 予約登録
│   └─ 各予約 → 予約編集
├─ 体重一覧
│   ├─ [＋体重登録]ボタン → 体重登録
│   └─ 各体重記録 → 体重編集
└─ ひとこと一覧
    ├─ [＋ひとこと登録]ボタン → ひとこと登録
    └─ 各ひとこと記録 → ひとこと編集

---

## 共通遷移ルール

- 登録完了後は、対応する一覧画面へ戻る。
- 更新完了後は、対応する一覧画面へ戻る。
- 削除完了後は、対応する一覧画面へ戻る。
- キャンセル押下時は、UI設計ルールに従ってキャンセル確認ダイアログを表示する。
- キャンセル確認ダイアログで「画面を離れる」を押下した場合は、前の画面へ戻る。

---

## 特殊な遷移

### ペット未登録の場合

予約一覧
↓
[＋予約登録]ボタン押下
↓
ペット登録済み？
├─ Yes → 予約登録画面
└─ No → ペット未登録時案内ダイアログ
           ↓
      [ペット登録へ]押下
           ↓
      ペット登録画面

※体重登録・ひとこと登録も同様の遷移とする。
