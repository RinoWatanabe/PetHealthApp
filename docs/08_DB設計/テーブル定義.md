# テーブル定義

## Pets

| 日本語名 | カラム名 | データ型 | PK | FK | 必須/任意 | 説明 |
|---|---|---|---|---|---|---|
| ID | id | BIGINT | 〇 | - | 必須 | PetsテーブルのID |
| ペット名 | name | VARCHAR(20) | - | - | 必須 | ペット名 |
| 種別 | pet_type | VARCHAR | - | - | 必須 | ペットの種別 |
| 種別(その他) | custom_pet_type | VARCHAR(20) | - | - | 任意 | 種別で「その他」を選んだときの種別名 |
| 年齢 | age | INTEGER | - | - | 任意 | ペットの年齢 |
| 性別 | gender | VARCHAR | - | - | 任意 | ペットの性別 |
| 誕生日 | birthday | DATE | - | - | 任意 | ペットの誕生日 |
