# バリデーション設計

## 共通ルール

- 登録ボタンまたは更新ボタン押下時に入力内容をチェックし、条件を満たさない項目のエラーメッセージを表示する。
- エラーメッセージは各入力項目の入力欄直下に表示する。
- エラーが表示された項目は、入力内容を再チェックし、条件を満たした時点で該当項目のエラーメッセージを非表示とする。
- エラーが表示された項目の入力欄は、エラー状態であることが分かるように表示する。（例：入力欄を赤枠で表示する）

## ペット

### ペット登録/編集画面

### ペット登録/編集画面

| 項目 | 必須 | バリデーション内容 | エラーメッセージ |
|------|------|--------------------|------------------|
| ペット名 | 〇 | 未入力不可 | 名前を入力してください。 |
| ペット名 | 〇 | 20文字以内 | 名前は20文字以内で入力してください。 |
| ペット名 | 〇 | 空白のみ不可 | 名前を入力してください。 |
| 種別 | 〇 | 未選択不可 | 種別を選択してください。 |
| 種別（その他） | 条件付き | 種別で「その他」を選択した場合、未入力不可 | 種別を入力してください。 |
| 種別（その他） | 条件付き | 種別で「その他」を選択した場合、20文字以内 | 種別は20文字以内で入力してください。 |
| 種別（その他） | 条件付き | 種別で「その他」を選択した場合、空白のみ不可 | 種別を入力してください。 |
| 年齢 | - | 半角数字のみ入力可能 | 半角数字で入力してください。 |
| 年齢 | - | 0～100の範囲で入力可能 | 0～100までの数字で入力してください。 |
| 年齢 | - | 整数のみ入力可能 | 整数を入力してください。 |
