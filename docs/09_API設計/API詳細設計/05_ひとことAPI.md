# ひとことAPI

## ひとこと一覧取得

### API概要

ひとこと一覧画面に表示する、ひとことの一覧情報を取得する。

### エンドポイント

GET /api/pets/{id}/notes

### リクエスト

- ペットID（URLのパスパラメータで渡す）

#### Request JSON

なし

### レスポンス

- ひとことID
- 記録日
- ひとこと

#### Response JSON

```json
[
    {
        "noteId": 1,
        "recordDate": "2026-06-01",
        "note": "今日はおやつを2回もねだった。かわいかったからあげちゃった😫"  
    },
    {
        "noteId": 2,
        "recordDate": "2026-06-02",
        "note": "今日は大好きなお散歩に行きたがらなかった。少し心配だな。"
    }
]
```

### 備考

- ひとこと一覧は選択中のペットに紐づく記録を取得するため、URLのペットIDで対象ペットを特定する。
- ペット切り替えタブに表示するペット名・ペット種別は、ペット一覧取得APIのレスポンスを使用する。
- 各ひとことを押下して編集画面へ遷移するため、レスポンスでひとことIDを返す。
- ひとことが1件も登録されていない場合は、空の配列を返す。

## ひとこと1件取得

### API概要

ひとこと登録/編集画面（編集）に表示する、登録済みのひとこと情報を取得する。

### エンドポイント

GET /api/notes/{id}

### リクエスト

- ひとことID（URLのパスパラメータで渡す）

#### Request JSON

なし

### レスポンス

- ひとことID
- ペットID
- ペット名
- 記録日
- ひとこと

#### Response JSON

```json
{
    "noteId": 1,
    "petId": 1,
    "petName": "ポチ",
    "recordDate": "2026-06-01",
    "note": "今日はおやつを2回もねだった。かわいかったからあげちゃった😫"  
}
```

### 備考

- 取得対象のひとことは、URLのひとことIDで特定する。
- 指定したひとことIDに該当するひとことが存在しない場合は、404 Not Foundを返す。

## ひとこと新規登録

### API概要

ひとこと登録/編集画面（登録）で入力したひとこと情報を新規登録する。

### エンドポイント

POST /api/notes

### リクエスト

- ペットID
- 記録日
- ひとこと

#### Request JSON

```json
{
    "petId": 1,
    "recordDate": "2026-06-03",
    "note": "今日は散歩中に近所のワンちゃんに会った。一丁前に威嚇をしていた。"
}
```

### レスポンス

- 処理結果
- ひとことID

#### Response JSON

```json
{
    "result": "SUCCESS",
    "noteId": 3
}
```

### 備考

- 登録後の一覧表示はひとこと一覧取得APIで行うため、レスポンスでは処理結果とひとことIDのみ返す。
