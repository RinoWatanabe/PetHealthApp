# エラー仕様

## 概要

APIでエラーが発生した場合は、HTTPステータスコードとエラー内容をJSON形式で返却する。

---

## HTTPステータス一覧

| HTTPステータス | 内容 |
| :--- | :--- |
| 400 Bad Request | リクエスト内容が不正な場合（入力値エラー・型不一致など） |
| 404 Not Found | 指定されたデータが存在しない場合 |

---

## 共通ルール

### 一覧取得API

- データが0件の場合でも404は返却しない。
- 空の配列を返却する。

### 詳細取得API

- 指定したデータが存在しない場合は404を返却する。

### 登録API

- 入力値が不正な場合は400を返却する。
- 関連データ（例：ペット）が存在しない場合は404を返却する。

### 更新API

- 入力値が不正な場合は400を返却する。
- 更新対象データが存在しない場合は404を返却する。
- 関連データ（例：ペット）が存在しない場合は404を返却する。

### 削除API

- 削除対象データが存在しない場合は404を返却する。

---

## エラーレスポンス

本アプリでは、エラー内容に応じて以下のレスポンスDTOを返却する。

| HTTPステータス | レスポンスDTO |
| :--- | :--- |
| 400 Bad Request | ErrorResponse |
| 404 Not Found | ApiErrorResponse |

---

## 400 Bad Request

### 発生条件

- リクエストDTOのバリデーションエラー
- PathVariableの型変換エラー

### レスポンス

```json
{
  "errors": [
    {
      "field": "petName",
      "message": "ペット名を入力してください。"
    }
  ]
}
```

### 対応クラス

- ErrorResponse
- ValidationErrorResponse

---

## 404 Not Found

### 発生条件

- 指定したデータが存在しない場合

### レスポンス

```json
{
  "status": 404,
  "message": "予約が見つかりません。"
}
```

### 対応クラス

- ApiErrorResponse
- ResourceNotFoundException

---

## 例外処理

本アプリでは、APIで発生した例外を `GlobalExceptionHandler` で共通的に処理する。

| 例外クラス | HTTPステータス | レスポンスDTO |
| :--- | :--- | :--- |
| MethodArgumentNotValidException | 400 Bad Request | ErrorResponse |
| ResourceNotFoundException | 404 Not Found | ApiErrorResponse |
