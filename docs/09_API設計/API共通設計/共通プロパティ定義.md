# 共通プロパティ定義

## 目的

APIのリクエスト/レスポンスJSON、DTO、Entityで使用するプロパティ名とJava型を統一するための定義書。

---

| 日本語名 | プロパティ名 | Java型 | 備考 |
|----------|--------------|---------|------|
| 予約ID | reservationId | Long |  |
| 予約日 | appointmentDate | LocalDate | 過去の予約を「前回通院」として表示する場合は、「通院日」として使用 |
| 病院ID | hospitalId | Long |  |
| 病院名 | hospitalName | String |  |
| 通院の目的 | visitReason | String |  |
| ペットID | petId | Long |  |
| ペット名 | petName | String |  |
| 種別 | petType | String |  |
| 種別（その他） | customPetType | String | 種別が「その他」の場合のみ使用 |
| 年齢 | age | Integer |  |
| 性別 | gender | String |  |
| 誕生日 | birthday | LocalDate |  |
| 体重ID | weightRecordId | Long |  |
| 測定日 | checkDate | LocalDate |  |
| 体重 | weight | BigDecimal |  |
| ひとことID | noteId | Long |  |
| 記録日 | recordDate | LocalDate |  |
| ひとこと | note | String |  |
| 処理結果 | result | String | SUCCESS / FAILURE など |

---

## ホームAPI用項目

| 日本語名 | プロパティ名 | Java型 | 備考 |
|----------|--------------|---------|------|
| 近日の予約一覧 | upcomingReservations | List | 近日の予約を複数件格納する |
| ペット別情報一覧 | petSummaries | List | ペットごとの基本情報・前回通院・最新体重・最新のひとことを複数件格納する |
| 前回通院 | lastVisit | Object | 過去の予約のうち最も新しい1件 |
| 最新体重 | latestWeight | Object | 最新の体重記録1件 |
| 最新のひとこと | latestNote | Object | 最新のひとこと1件 |
