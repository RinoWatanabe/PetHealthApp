# 技術選定

## 目的

このアプリを開発するにあたり、使用する技術を決める。

---

## 技術選定の方針

- 自分が学習・実装しやすいこと
- ポートフォリオとして説明しやすいこと
- MVPを完成させやすいこと
- 今後の自分のキャリアで活かしやすいこと

---

# 開発言語

## バックエンド

### 採用する技術

Java

#### 選定理由

- Javaの学習経験を活かしながら開発を進められるため
- Java Silverで学んだ基礎知識を実際のアプリケーション開発で定着させるため
- Spring Bootとの親和性が高く、バックエンド開発に広く利用されているため
- 今後のキャリアでも活用する機会が多いと考えたため

---

## フロントエンド

### 採用する技術

TypeScript

#### 選定理由

- 型安全な開発により、実装時のミスを減らしやすいため
- Javaで学んだ型の考え方を活かしながら学習できるため
- Reactと組み合わせて利用されることが多く、実務でも広く採用されているため
- 今後のキャリアでも活用する機会が多いと考えたため

---

# フレームワーク

## バックエンド

### 採用する技術

Spring Boot

#### 選定理由

- Javaとの親和性が高く、効率よくバックエンド開発を行えるため
- 学習や実務研修で使用した経験があり、知識を深めながら開発を進められるため
- REST APIの開発に広く利用されており、実践的なバックエンド開発を学べるため
- 実務でも採用される機会が多く、今後のキャリアでも活用できると考えたため

---

## フロントエンド

### 採用する技術

React

#### 選定理由

- フロントエンドとバックエンドを分けた構成を経験できるため
- Spring Bootで作成したAPIと連携する実装を学べるため
- 実務でも採用されることが多く、現場で活かしやすい技術だと考えたため
- バックエンドだけでなく、画面側の実装経験も積むことで対応できる範囲を広げたいため

---

# データベース

## 採用する技術

PostgreSQL

### 選定理由

- 学習や実務研修で使用した経験があり、知識を深めながら開発を進められるため
- Spring Bootと組み合わせて利用しやすく、バックエンド開発の学習に適しているため
- ペット情報、予約情報、体重記録、ひとこと記録などの関連するデータをテーブルとして管理しやすいため
- DB設計やSQLの理解を深めながら開発を進められるため
