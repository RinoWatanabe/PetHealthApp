# 画面一覧

## MVP（必要最低限な機能）

### ホーム

- 次回の予約を表示する
- ペットごとの最新の体重を表示する
- 最新のひとこと記録を表示する

※ 前回通院した日・病院名・目的は、通院履歴管理機能の追加後に表示する。

### ペット一覧

- 登録されているペットの一覧を表示する
- ペット登録/編集画面へ遷移できる

### ペット登録/編集

- ペットの情報を登録、編集できる

### 予約一覧

- 登録されている今後の予約一覧を表示する
- 予約登録/編集画面へ遷移できる

### 予約登録/編集

- 予約日を登録、編集できる
- 病院名を入力して予約を登録、編集できる
- 何の目的で通院するのか登録、編集できる

### 体重一覧

- 登録したペットの体重の一覧を表示する

### 体重登録/編集

- ペットの体重を登録、編集できる

### ひとこと記録一覧

- 登録したひとこと記録の一覧を表示する 

### ひとこと記録登録/編集

- 日々のひとことを登録、編集できる


## 余裕があれば

### 病院一覧

- 今まで通院した病院の一覧を表示する

### 病院登録/編集

- 通院した病院を登録、編集できる

### 体重推移グラフ

- 登録した体重をグラフで確認できる

### カレンダー表示

- 予約日が印で分かる
- 登録したひとことが、いつ登録されたものなのかカレンダーの印で分かる
